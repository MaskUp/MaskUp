- 🎬 **Emby** — movies, TV, and archived YouTube channels
- 📸 **Immich** — self-hosted replacement for Google Photos
- 📥 **Pinchflat** — automated YouTube channel archiving
- 💾 **3-copy backups**, because *one is none, two is one*
